# Facebook 采集方案选型与成本总结

> 整理时间：2026-08-07 · 调研详档：本目录 `facebook-groups.md`（主路线侦察+PoC）、
> `facebook-apis/`（官方渠道 + 第三方服务详档）
> 业务背景：线索售价 ¥3/条（WhatsApp 注册号·女）；青果代理 5 通道 ¥30/天（按天计费）

## 0. 一句话结论

**主路线自建（匿名抓群帖 permalink，青果代理），发现层可用 Apify Google SERP 外包（约 ¥13-32/万帖），Bright Data 免费层作灾备；官方 API 不接。** 按 ¥3/条售价，三条路线单条成本（¥0.01-0.3）都远低于售价，**成本不是决策变量，日产能才是**。

## 1. 各方案：怎么爬 + 什么成本

### ① 自建·匿名群帖 permalink（主路线，已落地）

- **怎么爬**：Google `site:facebook.com/groups` 发现帖 URL → CloakBrowser 匿名渲染 permalink（纯 HTTP 被 TLS 指纹拦截 400，必须浏览器）→ og:description + DOM 正文正则提号 → 按分层策略分桶（自声明 WA 不查 / 不确定过 wa_check）→ wa_check 验证注册态。全程**无需 FB 账号**。
- **已实现**：`fetcher` 的 `fetch_fb_post` 原子，真机 10 帖 10/10 成功，og 层号码 8/8 全对。
- **成本**：青果 5 通道 ¥30/天（与 1688 采集共用）+ 发现层 ~¥20/万帖 ≈ **¥0.01/条注册号**。
- **产能**：单通道 ~10s/帖，理论 ~8600 帖/天；5 通道理论 ~4.3 万帖/天，按 30-50% 安全系数规划 **1.5-2 万帖/天 ≈ 6000-8000 注册号/天**（过滤前）。
- **未测空白**：单 IP 匿名抓 FB 的安全日量（需一次半天爬坡实测定数）。

### ② Bright Data Scraper API（灾备/扩量备选）

- **怎么爬**：调「Posts by group URL」端点（`dataset_id=gd_lz11l67o2cb3r0lkj3`），传群 URL 列表拿回 JSON，平台侧代理/反爬全包。只覆盖公开群、无登录态。
- **字段偏薄**：官方示例仅 7 字段且作者名打码，互动数待实测。
- **成本**：**5K 条/月免费**（免信用卡）+ PAYG $1.5/1K 条 → 1 万帖/月 ≈ **¥54 ≈ ¥0.014/条注册号**。
- **定位**：免费层实测字段后作灾备；日量冲到 5 万帖以上时唯一能躺着扩量的选项。

### ③ Apify（发现层外包 + 字段对照基准）

- **怎么爬**：actor 市场，REST 调用返回 JSON。Groups Scraper（$5/1K 帖）结构化最全（permalink/正文/作者/互动数/top 评论）；**Google Search Scraper $1.8-4.5/1K 查询页**（查 1 次 ≈ 1.3 分钱）。
- **成本**：FB 全外包 1 万帖/月 ≈ ¥360（¥0.09/条），贵；**发现层外包 1 万帖的发现量 ≈ ¥13-32**，划算。
- **定位**：发现层（Google site: 查询）外包首选，免自建人机验证对抗；Free 档 $5/月可做零成本 PoC。另可作应急兜底和字段对照。

### ④ 官方渠道（调研后均不接）

| 渠道 | 结论 |
|---|---|
| Graph API | 读第三方公开数据全部需 Page Public Content Access（App Review 难过审），只适合做自有 Page 管理，**不接** |
| Ad Library API | 商业广告仅欧盟/EEA 定向可查（DSA），花费数据只给政治广告，token 需证件认证，**降为低优先级** |
| 网页版广告库 | 真实浏览器匿名可搜全球全量广告（裸 HTTP 403），与主路线共用 CloakBrowser 抓取层，**二期候选补充线索源** |
| Meta Content Library | 仅学术/非营利（ICPSR 审批+收费），商业用途不考虑 |

### ⑤ Oxylabs / Decodo（不推荐）

- 两家均无 FB 专用解析器（只回原始 HTML 自己解析）、均不支持登录态；1 万帖/月 ~$49（Oxylabs 最低消费）/ ~$20-50（Decodo 费率不透明）。性价比低于 Apify/Bright Data。
- 唯一价值：Decodo 住宅代理 PAYG $4/GB，可作青果之外的代理渠道补充候选。

### 共同边界（重要）

- **所有第三方服务 + 官方渠道都只支持公开群、全部不支持登录态**——私密群谁都补不上，花钱买不到比自建匿名路线更多的覆盖范围。
- 自建匿名路线落在 Meta v. Bright Data（2024）判例的"未登录抓公开数据"安全区；登录态抓取违反 ToS，不做。
- 评论留号是机会增量（无头会话渲染不稳定），稳定采集面 = og:description + 帖子正文。

## 2. 经济账（¥3/条售价）

漏斗实测：10 帖 → 10 号 → 5 注册（不确定桶 37.5%、自声明桶 ~100%），保守按 **0.4 注册号/帖**；「女」筛选按 30-50% 通过率另计。

- 单条注册号成本：自建/Bright Data ≈ **¥0.01-0.014**，Apify 全外包 ≈ ¥0.09；
- 单条可售线索（含女筛选）≈ **¥0.03-0.3**，对 ¥3 售价全部成立；
- **决策变量是日产能不是成本**：≤2 万帖/天自建最划算（与 1688 共用代理）；>5 万帖/天再考虑 Bright Data 按量扩。
